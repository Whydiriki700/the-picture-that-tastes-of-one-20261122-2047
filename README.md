A single mouthwatering food photograph: a rich, colorful Indonesian dish, steam rising, warm light, close-up. The entrypoint `main.py` writes the PNG (`entry.png`, 960x640, under 1 MiB) to the output directory.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
